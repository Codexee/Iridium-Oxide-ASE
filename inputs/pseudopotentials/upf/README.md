# Pseudopotentials

This directory contains pseudopotential files used for QE parent electronic-structure calculations in the pseudopotential-aware IrO2 workflow.

Current selection:
- SSSP Precision v1.3.0 (Materials Cloud)
- PBE-based scalar-relativistic pseudopotentials

These parent calculations provide the electronic structure used for downstream orbital analysis, active-space selection, and reduced Hamiltonian construction.

The pseudopotential-aware workflow is currently under active development on the `dev/pseudopotential-integration` branch.
